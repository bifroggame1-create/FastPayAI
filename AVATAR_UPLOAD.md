# Загрузка аватара в раздел "Мои магазины"

## Описание функции

Добавлена возможность загрузки и изменения аватара магазина в разделе профиля продавца. Функция включает предпросмотр изображения перед сохранением и полную интеграцию с API.

## Файлы, изменённые

### Frontend

#### 1. `/Users/onlyonhigh/work/WebAppAiShop/frontend/src/lib/api.ts`

Добавлена новая функция API для загрузки изображений:

```typescript
uploadShopImage: async (formData: FormData) => {
  const { data } = await adminApiInstance.post('/admin/my-shop/upload-image', formData, {
    headers: { 'Content-Type': 'multipart/form-data' }
  })
  return data
}
```

**Endpoint:** `POST /admin/my-shop/upload-image`
**Input:** FormData с полем `file` (multipart)
**Output:** `{ url: string }` - URL загруженного изображения

## Функциональность

### Процесс загрузки

1. Пользователь нажимает "Редактировать" в профиле магазина
2. Секция аватара становится видимой
3. Пользователь нажимает "Выбрать аватар"
4. Открывается диалог выбора файла (только изображения)
5. После выбора файла:
   - Проверяется тип (image/*)
   - Проверяется размер (≤ 5 МБ)
   - Создается preview через FileReader
   - Файл загружается на сервер
   - URL сохраняется в profileForm
6. Пользователь может отменить изменение перед сохранением
7. При нажатии "Сохранить" профиль обновляется

### Валидация

- **Тип файла:** Только изображения (image/*)
- **Размер:** Максимум 5 МБ
- **Ошибки:** Показываются через alert с описанием проблемы

### UI/UX элементы

- **Иконка placeholder:** SVG иконка картины для пустого аватара
- **Preview квадрат:** 24x24 пикселя с border-radius 8px
- **Loading spinner:** Анимированный спинер во время загрузки
- **Disabled состояние:** Кнопка отключена во время загрузки
- **Цветовая схема:** Соответствует темной теме приложения (Tailwind classes)

## Backend требования

Backend должен реализовать endpoint:

```
POST /admin/my-shop/upload-image
Headers: Content-Type: multipart/form-data
Body: FormData с полем 'file'
Response: { url: string } - публичный URL загруженного изображения
```

## Примеры использования

### Для Backend разработчика

Endpoint должен:
1. Получить файл из FormData
2. Валидировать размер и тип
3. Сохранить на сервер/облако (S3, Cloudinary, etc.)
4. Вернуть публичный URL

## Безопасность

- Frontend валидация размера и типа
- Использование multipart/form-data стандарта
- Backend должен дополнительно валидировать на сервере
- Рекомендуется использовать CDN для хранения изображений

## Ограничения текущей реализации

- Максимум 5 МБ (можно увеличить)
- Только формат multipart/form-data
- Синхронная загрузка (блокирует UI во время процесса)
